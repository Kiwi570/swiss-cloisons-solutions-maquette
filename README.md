# Swiss Cloisons Solutions · maquette v1

Direction « Verre & Lumière ». Site statique (HTML, CSS, JavaScript), sans étape de construction, prêt pour Vercel.

## Pages
- `index.html` : accueil (vitre WebGL, coupe axonométrique, réalisations, avant/après, méthode, carte du Léman, contact)
- `realisation-axa.html` : fiche réalisation AXA
- `devis.html` : demande de devis en 5 étapes (simulée, rien n'est envoyé)
- `mentions-legales.html` : mentions et confidentialité, à faire valider

## Contenus à compléter
Tout ce qui est marqué « à compléter » ou « à confirmer » à l'écran. Les visuels marqués « Visuel provisoire » seront remplacés par les images Grok (même nom de fichier dans `assets/img/`).

- Lenis 1.3.27 (MIT), assemblé depuis les sources
